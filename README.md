🔐 Keystroke Logging Demonstration (Educational Project)

📌 Overview
  This project is a controlled and ethical keystroke logging demonstration developed for cybersecurity learning and internship purposes.
  It demonstrates how keystroke logging works only with explicit user consent, using a graphical interface with Start and Stop controls.
  The project focuses on security awareness, defensive understanding, and ethical implementation, not malicious activity.
🎯 Project Objectives
  Understand how keystroke logging techniques work (educational) 
  Demonstrate controlled keyboard input capture 
  Provide start/stop logging functionality 
  Generate session-based reports automatically
  Promote ethical cybersecurity practices
🛡️ Ethical Notice (Important)
⚠️ This project is strictly for educational and cybersecurity awareness purposes.
  Logging starts only after clicking the Start button
  Logging stops immediately after clicking the Stop button
  No background spying
  No persistence on system startup
  No internet or data exfiltration
  No credential harvesting
  Unauthorized use of keylogging techniques is illegal and unethical.
🧩 Features
  ✅ GUI-based application (user-visible)
  ▶️ Start logging with button click
  ⏹ Stop logging instantly
  📄 Automatic keystroke report generation
  🕒 Timestamped report files
  🔐 Session-based logging only
  📂 Organized report storage
🛠️ Tech Stack
  Programming Language: Python
  GUI Framework: Tkinter
  Keyboard Listener: pynput
  Report Format: Text files
  Platform: Windows / Linux
